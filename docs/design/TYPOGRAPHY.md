# Typography

Space Grotesk 400/500/600/700: English display and UI. Fredoka 500/600/700: occasional expressive accents. M PLUS Rounded 1c 400/500/700/800: Japanese. JetBrains Mono 400/500/600: technical labels, observations and logs. All are Fontsource 5.3.0 WOFF2 files with their actual SIL OFL 1.1 notices copied verbatim.

No runtime Google Fonts or other font CDN requests. The original reference's Google CSS request is substituted with the same bundled faces only for reference screenshot capture. font-display: swap and local fallbacks allow offline operation. The Japanese subset contains Japanese and Latin glyphs; Space Grotesk takes precedence for Latin. No synthetic italic font file is distributed: italic display text matches the reference's synthesis.
