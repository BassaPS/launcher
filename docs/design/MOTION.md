# Motion

Tokens: immediate 120ms, hover 180ms, menu 240ms, dialog 300ms, page 320ms; standard cubic-bezier(.2,0,0,1), expressive cubic-bezier(.2,.8,.2,1). Motion acknowledges input or explains state. Use the reference's restrained button feedback. No persistent floating planets, randomized particles or parallax are added.

prefers-reduced-motion disables decorative movement and preserves all controls. Existing Launcher MotionConfig continues to use the user's reduced-motion preference.
