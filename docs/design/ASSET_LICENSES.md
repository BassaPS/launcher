# Assets and licenses

The four font families are bundled from Fontsource 5.3.0. Their package LICENSE files are copied without modification to public/bassaps/licenses and combined in licenses.txt. Font copyright names and SIL OFL conditions remain present. Fonts are unmodified WOFF2 subsets, not renamed derivative font families.

Existing Lucide icons remain the single application icon family; its MIT notice is included. Adopting another icon set would add dependencies and require migrating existing icons, so Phosphor was evaluated as a candidate but not mixed into this release. The planet/controller/wordmark shapes are adapted directly from the user-supplied reference. Existing Launcher art, upstream attribution and THIRD_PARTY_NOTICES remain unchanged. No new third-party game artwork is distributed.

The Material Design skill was read from https://github.com/skydashnet/material-design-3-ui-skill; it guides semantics/adaptivity/accessibility, not Google's visual appearance. The source revision is recorded in evidence; no remote installer was executed.
